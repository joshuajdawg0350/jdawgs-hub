What it does

  • Two decks + a set list: load your own audio files (file picker only — no mic, no camera), order them with big up/down controls, and play the set in the order you see.
  • Live crossfade: one oversized equal-power crossfade slider between Deck A and Deck B with a real master meter, plus a per-join fade length (2–12 seconds) for set playback and export.
  • Level the set: every track is measured (peak and RMS in dBFS, shown per track). One tap evens the set with compression/limiting under a −1 dBFS ceiling, with a before/after table and an A/B bypass so you hear the difference.
  • Genuine mix export: the whole set renders on your phone to a real 24-bit WAV or a real 256 kbps MP3 — byte-verified formats, never a relabeled capture. Real duration and file size are shown.
  • Try it first: a labelled SAMPLE set (two synthesized tracks, one deliberately quiet) runs the full flow — load, crossfade, level, export — with no files needed.

Honest limits — read these first

  • Files only: it mixes files you open in it. It cannot mix Spotify, Apple Music, YouTube, or any other app's stream — no browser app honestly can.
  • A crossfade is not beat-matching: no automatic BPM sync, key matching, stem separation, or AI mixing is claimed. Fade length is yours; levels are measured and evened.
  • Free DJ apps exist: edjing's free version and Cross DJ Free are named in the app as free alternatives. Our difference is no ads, no account, no trial/card wall, measured leveling, and export included in a file you own.
  • Rendered on your phone: very long sets are limited by phone memory; the app shows total duration and warns in plain words before rendering.
  • Disclosed, not verified: audible output through a real phone speaker and the native file picker with a user's real files could not be driven in the audit sandbox; the decode path is the same standard path exercised by the verified SAMPLE flow, and live meter levels/playback positions are the evidence available.
