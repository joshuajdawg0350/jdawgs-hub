What it is

Sideload Check is a web app you open on your phone — no app-store download, no account, no upload. Android is rolling out developer verification: from 30 September 2026, in Brazil, Indonesia, Singapore and Thailand, apps installed through participating app stores must be tied to a developer Google has verified, and a global rollout is planned for 2027. If you sell or share APK files directly — on Gumroad, itch, or your own site — you need to know what your file actually says and what it can't prove. Sideload Check reads the file for you, in plain words, entirely on your device.

Two modes, one report: Seller mode — "is my APK ready, and what's left that only registration can settle?" — and Buyer mode — "a seller sent me this APK; what is it, and what will it ask my phone for?"

What it does

  • Identity card — package name, version, file size, and min/target Android levels translated into version names people recognize
  • Signing card — which signature schemes the file actually carries (v1, v2, v3 and friends); the signer's certificate subject, validity dates, and fingerprint are shown only when they were genuinely read from the file — otherwise the card says so
  • Permissions in human words — every permission the app declares, translated into a plain sentence, with the ones Android makes the phone ask about first flagged plainly
  • Readiness checklist in three honest parts — what this file proves, what only Google registration can prove, and the three routes (full distribution, limited distribution for up to 20 devices, or unregistered with the ADB / advanced-flow path), with the phased timeline stated accurately and dated
  • Honest edge cases — split packages (XAPK), app bundles (AAB), and corrupt or non-APK files get a plain explanation, never a made-up report
  • Built-in samples — two clearly labeled sample reports (one well-formed and signed, one with gaps) so you can see the whole report before trusting it with a real file
  • Private by design — every byte is parsed on your device; the APK never leaves your phone; works fully offline after it loads

The honest limits — printed here and in the app

  • Registration status lives with Google and cannot be read from any file. This app verifies the file side and explains the rest — no tool honestly can read Google's registry out of an APK.
  • This app cannot tell you whether an APK is safe. It reads the manifest and signing facts; it does not scan code behavior and gives no malware verdict, no risk score, and no readiness percentage.
  • Signature presence is not a validity guarantee — the report states which schemes are present and what was actually read from the certificate.
  • Sideloading is not banned, and direct APK downloads are not covered by the first enforcement phase — the app states the phases as they are (checked November 2026), never scarier.
  • Disclosed-not-verified in our build audit: picking a real file through the phone's file picker and dragging-and-dropping on a real device (the audit sandbox cannot inject real files — both use the exact parser our audit validated in Node against 37 constructed test files).
