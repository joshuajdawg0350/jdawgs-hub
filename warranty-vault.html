Return windows close in weeks. Warranties run for years — and most people find out theirs expired the day something breaks. Warranty Vault tracks every cover on every item, and puts your serial, proof, and claim contact on one screen the day you need them. $3.99 once.

What it does

  • Multi-cover per item: manufacturer warranty, store/extended plan, and credit-card extension on the same fridge, washer, or drill — each with its own end date and claim contact. Every card answers "covered until when, by whom."
  • Coverage home screen: items sorted by nearest cover expiry across all covers. Expired covers stay visible, labeled EXPIRED — never silently dropped.
  • Claim-day helper: one screen per item with its serial/model, purchase date and proof, the covers still in force, and who to call — ready before you dial.
  • Reminders that are honest: .ics calendar files with 30-day and 7-day alarms before each cover expires. No fake push notifications.
  • Coverage report, always free: a printable, downloadable report generated on your device — never gated.
  • Try it first: a labeled SAMPLE household (fridge, washer, drill) runs the full flow and removes cleanly.

Honest limits — read these first

  • This app records the coverage you type in. It does not verify coverage with any manufacturer or store, does not file claims, and cannot guarantee a claim outcome — a lapsed or excluded claim stays lapsed.
  • Records and receipt photos live on this device only. The coverage report export is your backup — use it.
  • Reminders are calendar files (.ics), not a notification service.
  • Not the return app: for store return deadlines, that's J-Dawgs Return Window Vault — this app is for the years after the return window closes.
  • Disclosed-not-verified in our build audit: the receipt-photo file picker on a real phone, the report file landing in a real Downloads folder (same download path as the verified .ics export), and the storage-blocked session-only fallback (code-inspected; storage is fully guarded).
