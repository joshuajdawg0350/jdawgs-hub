✅ The code word

—

Ask for it on any call that asks for money, codes, or secrecy. Real family knows it instantly. A cloned voice doesn't.

🆘 The duress word

—

Works the other way: if YOU are ever forced to make a call, or a caller uses this word, it means "this is not real — hang up, send nothing, call back on the real number and check on me." It must sound ordinary in a sentence: "Tell everyone the word is …" should never happen — instead it slips in naturally, like "…and grab the … while you're out."

Backup questions (answers that are NOT online)

Use these when a code word isn't practical — on a first call to set up, or with relatives who can't manage codes. Strong questions are about shared experiences, not facts: birthdays, schools, pet names, and maiden names are all findable or guessable, and classic "security questions" are the first thing a scammer researches.

The rules that make it work

1. Agree it in person or on a call you placed. Never set or change the code word on an inbound call or by text — that's exactly the channel scammers control. 2. Never post it, text it around, or put it in a group chat. Share it face-to-face or by a call you dialed. 3. One word for the whole circle. Simplicity beats cleverness at 2 a.m. during a panic call. 4. Change it if it leaks, the same day, the same in-person way. 5. Practice once. Run the Scam Drill together so the first time anyone hears "what's the code word?" isn't during a real emergency.

Put the finished kit on the fridge with the Family Card, and use CallCode when you want a fresh code every five minutes instead of one fixed word.
